- Код и тексты из чужого PR, влитые вручную: автор коммита — автор PR (его GitHub-почта, для

## Pull request'ы

- Проверить по существу (ссылки, якоря, команды, факты — по возможности на устройстве),
  привести к стилю вики: строки ~100 символов, `-` для списков, язык у блоков кода, пустая
  строка перед списком, картинки в `docs/assets/images/`, безличный стиль (не «я сделал»).
- PR без правок или с мелкими правками — сливать через GitHub (squash merge), чтобы PR был
  «Merged» и автор попал в контрибьюторы; правки — следующим коммитом.
- Каждого автора влитого PR добавить в `docs/contributors.md` (ссылка на профиль, что добавил,
  номер PR). Данные для страниц моделей — туда же, в отдельную таблицу.
- Комментарии на GitHub — коротко и по делу: что влито, каким коммитом, что поправлено.
