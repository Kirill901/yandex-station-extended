# Начало работы

Четыре шага по порядку. Первые два обязательны: без второго Яндекс может прислать
обновление и закрыть доступ.

| Шаг | Что делаем | Время |
|---|---|---|
| 1. Получение root | способ зависит от модели — см. таблицу ниже | ~15 мин |
| 2. [SSH и обновления](ssh.md) | блокируем OTA, ставим SSH | ~5 мин |
| 3. [Пакеты `yse`](packages.md) | Entware: тысячи готовых программ | ~5 мин |
| 4. [Если что-то сломалось](recovery.md) | диагностика и откат | — |

## Шаг 1: какой способ для вашей колонки { #root-by-model }

| Модель | Способ |
|---|---|
| Лайт, Мини, Мини 2, Мини 3, Миди, Станция 2, Стрит, Умный хаб | [DNS-метод](root.md): сброс, DNS на роутере, ADB по сети |
| **Лайт 2 (Plum)** | [retail CA из factory](retail-ca.md) — патч CA-бандла в factory mode |
| Станция Макс, Станция 1-го поколения | способа пока нет (Android-платформа) |

Без компьютера, с Android-телефона: [AliceBridge](root-android.md).

Дальше — [рецепты](../recipes/index.md).
